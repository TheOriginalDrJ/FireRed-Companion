# FireRed Companion — First Release

Bring your first party Pokemon along as an overworld companion in FireRed Recomp.

## Included

- First-slot following, including fainted Pokemon.
- Smooth connected-route transitions without resetting the companion's trail.
- Talk with **A**, collect occasional gifts, and watch for its **!** attention bubble.
- **POKEMON FOLLOW → ENABLE / DISABLE** in Options.
- Persistent gift/progress state and safe full-Bag handling.
- Red Rescue Team artwork: **423 sprite sets, 93,591 poses**, and mappings for all **386 Gen 1–3 species**.

## Installation

Download **PokemonCompanion-FireRed-v0.1.2.zip**, import it through Recomp's mod manager, enable **Pokemon Companion**, and restart. Replace previous versions rather than enabling duplicate copies. No new save is needed.

This is the first GitHub release; v0.1.2 includes the initial companion features plus smooth route transitions and fainted-lead support. Native-engine tests passed. Companions temporarily withdraw during cycling, Surf and Fly. The specific Hoenn 124/125 pair has not been playtested with the full Hoenn mod enabled.

The ZIP includes the mod and its extracted assets; it does not include a ROM or the engine. See the repository README for compatibility and source details.
